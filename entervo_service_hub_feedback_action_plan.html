entervo Service Hub — Simple Action Plan

A simple overview of changes requested by the team and how we will implement them.

1. Operators & Cell Computers Priority 1
"Connection details should belong to cell computers; one operator can have several."
  • Operator Level: Set Country, Language, Currency, and VAT once at the top.
  • Cell Computers: Add multiple cell computers per operator, each with its own IP, Port, URL, and login details.
2. Facilities & Services Priority 1
"Each facility needs a cell computer link, and only uses certain services."
  • Cell Computer Link: Pick which cell computer runs each parking facility.
  • Service Checkboxes: Check off only the active services (e.g. Validation, entervo connect) instead of forcing all of them.
3. Smart Payment (PSP) Display Priority 1
"A Payment Provider is not needed for Validation onboarding."
  • Clean Workflow: Automatically hide payment & PSP fields when onboarding Validation-only sites.
  • No Confusion: Payment fields only show up when a real payment product (like smart-web-pay) is selected.
4. All-in-One Products Page Priority 2
"Make all steps in one page with a copy button for new Excel versions."
  • Single Page: Review and edit all product settings on one clean page instead of clicking back and forth.
  • Copy Button: 1-click button to copy the entire configuration to clipboard. Ready for the new Excel sheets!
5. Usability, Drafts & Split-Screen Layout Priority 2 & 3
"Couldn't restore saved draft; half-screen cuts off content; no email on user creation."
  • Easy Draft Restore: Clear "Resume Saved Draft" banner so your work is never lost.
  • Split-Screen Friendly: Collapsible sidebar and smooth scrolling so nothing is cut off on half a screen.
  • User Invite Link: Send an invite email or copy the activation link directly.
  • Dark Mode: Optional switch for comfortable night/dark viewing.
Phase What We Are Changing User Benefit
Phase 1 (Now) Cell Computers, Facility Links & Hide PSP Match real-world parking hardware; remove misleading payment fields.
Phase 2 (Next) Single-Page Product View + Copy Button Configure products 3x faster and copy setups in 1 click from new Excel sheets.
Phase 3 (Final) Draft Restore, Split-Screen & User Invites Never lose draft work; comfortably use the app on any screen size.
